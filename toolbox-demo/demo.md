# 工具箱演示 Markdown

## 简介

这个文件演示了 **Write 工具** 生成 Markdown 格式文件的能力。

## 支持的元素

- **粗体** 和 *斜体*
- `行内代码`
- 列表项
- 表格：

| 格式 | 扩展名 | 生成工具 |
|------|--------|----------|
| Word | .docx | office-plugin:docx |
| Excel | .xlsx | office-plugin:xlsx |
| PPT | .pptx | office-plugin:pptx |
| PDF | .pdf | office-plugin:pdf |

## 代码块

```python
print("Hello from Markdown!")
```
